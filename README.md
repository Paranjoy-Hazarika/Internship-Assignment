# Internship Assignment

🔗 **Preview URL:** [https://paranjoy-internship-assignment.netlify.app](https://paranjoy-internship-assignment.netlify.app)

This project is a responsive webpage built using **HTML**, **CSS**, **Bootstrap**, and **JavaScript**, based on the design provided by Workik.

---

## 🖥️ Overview

The webpage matches both the **desktop** and **mobile** versions of the provided design.  
Tablet responsiveness has been implemented manually for better adaptability.

---

## ⚙️ Technologies Used

- HTML5  
- CSS3  
- Bootstrap 5  
- JavaScript

---

## 📱 Features

- Fully responsive layout (desktop, tablet, and mobile)
- Hamburger menu with smooth animation
- Clean and organized Bootstrap grid system
- Follows provided color palette and typography closely
- Optimized spacing and alignment for professional appearance

## How to Run

```bash
git clone <repo-link>
npm install
npm run dev
```
